# UI 风格指南 — HCP Personalized Engagement Assistant

> 基准日 2026-07-16 · 实现栈：Next.js App Router · Tailwind 4 `@theme` · Tremor · ECharts  
> 受众：药企商业 / 医学事务 / 市场人员（访前准备、Insights 阅读、Options 迭代）  
> 产品气质：**简单、专业、性冷淡**（冷静、少装饰、信息优先）

---

## 1. 设计立场

### 1.1 产品与页面职责

| 项 | 定义 |
|----|------|
| 产品 | 为指定 HCP 建立**数字分身** → 阅读 **HCP 洞察** → 产出 **一人一策** → **HCP Engagement Agent** 迭代 |
| 首屏工作 | **HCP列表**；「打开」后以姓名标签多开工作台；洞察与一人一策在工作台子 Tab |
| 洞察报表 | HCP 洞察：一句话洞察、科研方向（含成果）、活动热力表、兴趣方向、可能的机会、证据 |
| 界面语言 | 默认 `zh-CN`；顶栏切换中英；UI 壳与职业轨迹走 i18n catalog；叙事按 `locales` 中英分桶展示（互不覆盖）；生成跟当前 locale；姓名主展示 `name_zh`，有拉丁 `name_en` 时 English Tab 用英文名 |

### 1.2 视觉一句话

**「冷灰底上的病例夹」**：像整理好的临床卷宗与合规档案——留白充足、字重克制、强调用一条沉静的墨蓝，不用暖色情绪或科技霓虹。

### 1.3 刻意不做（行业 × 反模板）

| 不做 | 原因 |
|------|------|
| 暖奶油底 + 衬线大标题 + 陶土色 | 与「性冷淡」相反，且属常见 AI 默认套 |
| 深紫 / 靛蓝渐变 Hero | 通用 SaaS 模板感 |
| 近黑底 + 荧光绿 / 朱红 | 「科技仪表盘」套路，不适合规医疗商务 |
| 密排报纸栏 + 零圆角发丝线 | 编辑部美学，阅读成本高 |
| 卡片堆叠 Hero、浮动徽章、多阴影 | 干扰「一人一策」信息主线 |
| Emoji、插画吉祥物、圆角药丸标签簇 | 专业场景噪音 |

### 1.4 签名元素（全站只记一件事）

**Specimen Index（标本索引条）**  
页面左侧（桌面）或顶栏下方（移动）固定一条 **28–32px 宽的竖向索引区**：仅在**顶栏聚焦某姓名分身标签**（含其 HCP资料/洞察/一人一策）时显示该 HCP 姓氏缩写 + 置信度点；**HCP数字分身列表 / Agent / 新增向导**时为占位「—」。像病理标本编号条，而不是 Logo 墙或彩色导航。  
其余界面保持安静；运动与强调都让位给这条索引与洞察报表的时间轴主脊。

## 2. 设计令牌（Token System）

在 `apps/web` 用 Tailwind 4 `@theme` / CSS 变量实现；组件禁止写死游离色值。

### 2.1 色彩

| Token | Hex | 用途 |
|-------|-----|------|
| `--hca-bg` | `#F2F3F5` | 页面底（冷灰，非暖米） |
| `--hca-surface` | `#FFFFFF` | 主内容面、报表区块 |
| `--hca-ink` | `#1C1F26` | 正文、标题 |
| `--hca-ink-muted` | `#5C6370` | 次要说明、元数据 |
| `--hca-line` | `#D8DCE3` | 分割线、表框、输入描边 |
| `--hca-accent` | `#2F4A56` | **唯一强调色**（墨蓝灰）：链接、选中、主按钮、图表主系列 |
| `--hca-on-accent` | `#F4F7F8` | 强调底上的文字/图标（冷白；禁止再用 ink 压在 accent 上） |
| `--hca-accent-soft` | `#E8EEF0` | 选中底、轻高亮 |
| `--hca-ok` | `#3D6B5A` | 合规「附条件通过」等冷静绿（低饱和） |
| `--hca-warn` | `#8A6A3B` | 待确认 / medium 置信（低饱和琥珀） |
| `--hca-danger` | `#8B3A3A` | Fail-fast / 拒绝（低饱和砖红，非亮红） |

**规则**

- 同一屏强调色面积 ≤ 5%；主 CTA 仅用 `--hca-accent` 实心或线框一种形态。
- 图表系列：主色 `--hca-accent`，辅色仅用灰阶递进（`#9AA3B0` → `#C5CAD3`），禁止彩虹多色饼图。
- 置信度：`high` → ink；`medium` → warn；`low` → muted + 虚线边；不用红绿灯大圆点装饰。

### 2.2 字体

| 角色 | 字体 | 说明 |
|------|------|------|
| **Display** | **Source Serif 4**（拉丁）+ **Noto Serif SC**（中文） | **仅**用于 HCP 姓名、Insights 页主标题；字重 500–600；克制字号 |
| **UI / Body** | **IBM Plex Sans** + **Noto Sans SC** | 导航、表单、正文、Options、对话 |
| **Data / Mono** | **IBM Plex Mono** | PMID、clause_id、`hcpId`、版本号、时间戳 |

**字阶（桌面）**

| Token | Size / Line | 用途 |
|-------|-------------|------|
| `display` | 28–32 / 1.25 | HCP 姓名 |
| `title` | 20–22 / 1.35 | 区块标题（职业轨迹、科研动向） |
| `body` | 14–15 / 1.55 | 正文 |
| `caption` | 12 / 1.4 | as_of、来源、合规旁注 |
| `mono` | 12–13 / 1.4 | ID、引用键 |

禁止：Inter / Roboto / Arial 作为品牌字体；禁止全页大号衬线。

### 2.3 间距与圆角

| Token | 值 | 用途 |
|-------|-----|------|
| `--space-1`…`--space-8` | 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 px | 唯一间距阶梯 |
| `--radius-sm` | 2px | 输入、表单元格 |
| `--radius-md` | 4px | 面板、按钮 |
| `--radius-lg` | 6px | 报表外框（最大） |

阴影：默认 **无投影**；仅浮层（Dialog / Popover）使用 `0 1px 0 rgba(28,31,38,0.06), 0 8px 24px rgba(28,31,38,0.06)`。

### 2.4 布局骨架

```text
┌────┬──────────────────────────────────────────┐
│ Idx│  Top: [双人图标] 单行字标 | 导航 Tab …      │
│ 本 │──────────────────────────────────────────│
│ 条 │                                          │
│    │   主列：当前页内容（max-width 1120）       │
│    │   洞察页：报表区全宽                        │
│    │                                          │
└────┴──────────────────────────────────────────┘
```

- 主列最大宽 **1120px**，左右边距 ≥ 24px（桌面）。
- 顶栏（`.hca-shell-bar`）：品牌、导航 Tab、语言切换 **同一 UI 字体 / 14px / 500**；状态仅靠颜色与选中底区分，不改字号。
- 顶栏品牌（`AppBrand`）：**双人线稿图标** + 单行字标「HCP Engagement 智能助理 / Assistant」；右侧细竖线与导航分隔；点击回列表。
- 文字 Tab：**HCP数字分身** ·（可选多开）**{姓名}** · **HCP Engagement Agent**；姓名标签悬停显示圆形关闭 `×`。
- 分身工作台内子 Tab：**HCP资料** / **HCP洞察** / **一人一策**（不用彩色进度环）。
- 卡片：默认**无卡**；仅交互容器（表单区、一人一策选项卡、对话输入坞）保留浅底 + `--hca-line` 边框。
- **级别标签**：见 [`knowledge/hcp-twin/hcp-tagging.md`](../knowledge/hcp-twin/hcp-tagging.md)；对比底色、无 emoji。
- **i18n**：界面文案与职业轨迹展示键入 message catalog；默认 zh-CN；顶栏「中文 \| English」切换并 persist。

## 3. 动效

性冷淡 ≠ 无动效；动效必须**短、静、可关**。

| 场景 | 规格 |
|------|------|
| 页切换 | 内容区 opacity 120ms + 4px 上移；`prefers-reduced-motion: reduce` 时关闭位移 |
| Specimen Index | 切换 HCP 时缩写字淡入 150ms |
| 报表加载 | 骨架屏用 `--hca-line` 脉冲，禁止彩色 spinner |
| 图表 | ECharts 入场 animationDuration ≤ 400ms；系列 stagger 禁止夸张弹跳 |
| Hover | 链接/行：`ink` 不变，仅底色 → `--hca-accent-soft` |

全站编排：**一次入口静默**（首屏索引条 + 标题出现），不做持续背景粒子或视差。

## 4. 文案语气（界面）

| 原则 | 正例 | 反例 |
|------|------|------|
| 用户语言 | 「生成 Engagement 方案」 | 「触发 Agent Orchestration」 |
| 主动、具体 | 「保存本次修订」 | 「提交」 |
| 失败可修复 | 「未消歧：请补充医院官网链接」 | 「出错了，请重试」 |
| 合规旁注 | caption 灰色，句首不加感叹 | 「警告！！必须备案」 |
| 空状态 | 「新增数字分身后开始构建」 | 「暂无数据 ✨」 |

## 5. 页面级规范

### 5.1 数字分身

#### 5.1.1 列表（入口默认）

- 标题为「HCP列表」；副文案「共 N 位HCP」（无「数字分身」eyebrow）。
- **表格式**：表头（# / 医生·机构·洞察 / 标签 / 操作）；每行左侧序号 `01` + accent 竖线。
- 行内：`hcp:{id}` mono、医院与科室分行、一句话洞察、级别标签对比底色。
- 行操作：**仅「打开」**；「修改 / 删除」在分身工作台。主操作「新增数字分身」。
- 顶栏默认仅「HCP数字分身」「HCP Engagement Agent」。列表有数据 ≠ 已打开工作台。

#### 5.1.2 分身工作台 · HCP资料

```text
[ HCP资料 | HCP洞察 | 一人一策 ]     [ 修改 ] [ 删除 ] [ 关闭本页 ]
[ 姓名 Display ]  [标签]
[ 智能体情报构建（常驻）          [ 构建情报 | 重新构建情报 ] ]
  · 未构建：尚无情报
  · 已构建：情报构建状态· Stage A–E 完成（100%）+ A–E 列表
  · 构建中：轮询进度；无「收起进度」
[ 一句话洞察 ]
[ 文献检索号 mono ]
[ 职业轨迹（垂直时间轴 · 按界面 locale 展示） ]
```

- 无「返回列表 / 返回数字分身」条；关页用顶栏姓名标签 `×` 或「关闭本页」。
- **智能体情报构建**区常驻于 HCP资料；构建按钮在该区右上角与标题对齐；不出现在洞察/一人一策。
- **一句话洞察**与**职业轨迹**在 HCP资料，不放在 HCP 洞察。
- 职业轨迹：界面为中文时展示中文类型与职衔译法；切换 locale 时走同一套 i18n 映射。
- 级别标签：对比底色；每行最多主标 + 3 辅标。

#### 5.1.3 编辑（新增 / 修改）

- **新增**：进入空白表单（姓名、医院、科室、城市**不预填**任何样例 HCP，含朱同玉）；可选 placeholder 仅作填写提示，不得写成具体医生姓名。
- 单列表单：姓名、医院、科室（城市可选）；主按钮「查询 HCP」（新增）或「保存修改」（编辑）。禁止主按钮文案「构建分身」。
- 阶段文字：身份锁定 → 职业 → 科研 → 洞察。
- **消歧候选（以人为主体）**：
  - 主标题必须是**医生姓名**（Display）；下一行医院，再一行科室 · 职称。
  - 禁止把「医院专家页 / OpenAlex Author / 网页标题」当作候选主标题——那些是**命中依据**，用次级标签展示。
  - 用一句业务可读的「如何区分同名」说明；匹配度用中文（匹配较稳 / 需核对 / 证据不足），不裸写 `high` + 原始 URL。
  - 主按钮文案：「就是这位」（进入预览确认）；左侧 3px accent 竖线标出较稳匹配。
- 文献检索号码：锁定后只读 mono 表；P0 全空阻断科研灌库。

### 5.2 HCP 洞察（工作台子 Tab）

```text
[ 姓名 ] [标签] [as_of] [导出]
[ 一句话洞察 ]
[ 科研方向 ] …
[ 活动热力四列表 ]
[ 已知近期学术活动 ]
[ 兴趣方向 ]     [ 可能的机会 ]
[ 证据与来源 ]
```

| 元素 | 规范 |
|------|------|
| **页壳** | 嵌于分身工作台；无「返回数字分身」条（关页用顶栏 `×` / 关闭本页） |
| **一句话洞察** | 摘要条 + 可选分析段；与 HCP资料同源 |
| **兴趣方向** | 多轴：标题 + 分析文 + 分桶/合规旁注 |
| **可能的机会** | 优先级、「不假设」；对接一人一策 |
| **科研方向** | 每方向下列成果，不用彩虹图 |
| **活动热力** | 四列表格；空窗写 caption |
| **证据表** | 来源可链；置信 / as_of |
| **KPI** | ≤3；禁大色块卡墙 |

### 5.3 一人一策（工作台子 Tab）

- 嵌于分身工作台；无「返回数字分身」条。
- 3–5 条方案用**选项卡**；字段：动作 → 负责人 → 渠道 → 内容主题 → 成功信号 → 合规旁注 → 优先级。
- 主操作：「生成方案」「送合规闸门检查」。
- **页面最下方**：嵌入「与 Agent 讨论本方案」短对话。完整 Agent 见 §5.4。

### 5.4 HCP Engagement Agent

页面主标题为 **「HCP Engagement 智能助理」**（无副标题/eyebrow）。通用对话（不展示/不绑定「当前 HCP」）；与一人一策页底 `revise_options` 分 mode。

```text
┌─ 历史会话（左栏）─┬─ 对话区 ──────────────────────┐
│ 会话列表          │ 消息流 + typing 等待态         │
│ （localStorage）  │ 附件预览                      │
│                   │ 输入坞 + 上传附件              │
│                   │ hint: Enter 发送 / Shift+Enter │
│                   │ 右下角手柄 → resize 面板       │
└───────────────────┴───────────────────────────────┘
```

| 能力 | 规范 |
|------|------|
| 标题 | 「HCP Engagement 智能助理」；不展示 mode 技术说明副文案 |
| 范围 | 通用 Agent；不默认注入分身洞察；分身级修订走一人一策页底 |
| 历史 | 左栏列表；**localStorage** 存索引与消息正文（不按 HCP 过滤） |
| 等待 | 发送后显示「正在回复」typing；按钮「发送中…」 |
| 快捷键 | Enter 发送；Shift+Enter 换行；输入区旁 hint |
| 上传 | 输入坞旁「附件」；展示文件名列表 |
| Resize | 对话面板拖动改变宽/高；`min-width` / `min-height` 有下限 |
| 气泡 | 用户：`--hca-accent-soft`；助手：透明 + 左边线 accent |

一人一策页底短对话同样具备 typing、Enter/Shift+Enter hint，且聊天按 `hcpId+runId+optionId` 写入 localStorage。

## 7. 无障碍与质量底线

- 对比度：正文与标签底色字色 ≥ WCAG AA。
- 键盘：Tab 可走完导航、列表、选项卡、对话。
- `prefers-reduced-motion` 关闭位移动画。
- 断点：Agent 左栏 &lt;768 改为顶栏抽屉；活动热力表横向滚动。

- [ ] 顶栏是否可切换中文 / English，刷新后 locale 保持，且 `<html lang>` 同步？
- [ ] 界面为 zh-CN 时职业轨迹类型/职衔是否中文展示；切到 en 后壳与轨迹是否英文 catalog？
- [ ] 列表/资料/构建/洞察/一人一策/Agent 主路径 UI 壳是否无残留硬编码中文（业务数据除外）？
- [ ] 级别标签是否有对比底色且无彩虹/emoji？
- [ ] 活动热力是否为四列表格？
- [ ] 一人一策是否为选项卡 + 底部对话？
- [ ] Agent 是否为通用对话（无「当前 HCP」绑定）、含本机历史、typing、Enter 提示、附件、resize？
