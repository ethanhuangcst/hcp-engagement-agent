# 中国市场 HCP Engagement / 学术推广合规闸门

本技能是 `non-cn-hcp-compliance` 的中国市场对应物：同样做「对外发布前的合规闸门」，但规则、监管主体与高风险场景替换为中国语境。

**管辖范围：** 仅中国大陆市场（药品上市许可持有人及其委托方在中国对 HCP / 公众的信息传递与互动）。港澳台或海外市场不在本技能内。

## Cardinal Rule（首要规则）

未经医学 + 法务 + 注册/法规（MLR）三方书面批准的对外材料，不是「已审批」，只是「已发表」。  
任何面向外部受众的资产——拜访话术、科室会材料、企微/公众号推文、线上会课件、讲者大纲、患者教育页、HCP Engagement 建议文案——在离开内部审核前，须留存三方签字（或等效电子签+时间戳）。审核是证据链，不是仪式。

本技能给出的「通过 / 附条件通过 / 拒绝」是**辅助闸门**，不能替代持证医学人员、公司法务与注册事务的正式签核。

## Fail-Fast Rule（立即拒绝）

出现下列任一项时，停止并返回结构化拒绝（见文末输出格式）：

1. **超适应症 / 未批准人群或用法**：内容暗示或明示的适应症、剂量、给药途径、患者人群超出当前 NMPA 批准说明书（或已备案说明书变更）。
2. **疗效比较无头对头证据**：宣称更优 / 非劣 / 等效，却无充分效能、经同行评议的头对头试验作为主证据。
3. **处方药公众端变相推广**：以科普、直播、挂链接、专家背书等形式向公众推销处方药，或医务人员互联网健康科普落入负面清单情形（变相广告）。
4. **学术推广程序缺失**：院内/面向医疗卫生机构的学术推广未取得机构同意，或由**未备案**医药代表开展。
5. **《医药代表管理办法》负面清单行为**：承担销售任务、统计医生处方、商业贿赂/回扣、误导用药、违规收集患者信息等。
6. **利益与处方挂钩**：讲课费、顾问费、餐费、捐赠、学术机会与处方量、进院、带量采购执行量挂钩或变相挂钩。
7. **绝对化 / 无依据最高级**：如「最好」「首选」「唯一」等无法用可审计、现行证据支撑的表述。
8. **未上市产品促销语境**：临床试验中或尚未获批产品，在促销性材料中使用疗效语言、结局预测或按适应症人群定向。

## When to Apply

在以下场景**主动使用**本技能：

- 审核或起草中国市场 HCP 互动材料（拜访要点、科室会、城市会、线上会、企微私域内容）。
- 评估 HCP Engagement Options / Assistant 输出是否可对外落地。
- 审查讲者费、顾问会、捐赠赞助、CSO/会议公司安排。
- 评估患者支持项目（PSP）、疾病教育、真实世界研究合作中的推广边界。
- 设计会收集 HCP/患者个人信息的活动数据与企微运营方案。

**不要**用于：临床试验方案设计、注册申报策略、药物警戒信号管理（转相关临床/注册技能）。  
**不要**单独用于美/欧/英/巴市场（用 `non-cn-hcp-compliance`）。

## 中国合规锚点（框架地图）

| 层级 | 文件 / 主体 | 本技能用法 |
|------|-------------|------------|
| 法律 | 《药品管理法》《广告法》《反不正当竞争法》《个人信息保护法》 | 标签一致性、广告边界、商业贿赂、数据处理 |
| 部门规章/办法 | 《医药代表管理办法》（**2026-08-01 施行**） | 备案、MAH 主体责任、机构同意、负面清单、联合惩戒 |
| 互联网 | 互联网药品信息服务备案相关规定；医务人员互联网健康科普负面行为清单 | 科普 ≠ 处方；禁止处方药直播带货式路径 |
| 行业自律 | RDPAC《行业行为准则》（及 IFPMA 原则在中国的落地） | 医学互动目的、信息标准、招待/赞助边界 |
| 企业私有 | 客户 SOPs / 合规手册 | 租户规则优先于泛化建议；冲突时取更严者 |
| 标签真相源 | 现行 NMPA 批准说明书 | on-label / off-label 唯一判定基准（非临床惯例） |

时效敏感点须标注 `as_of`；办法实施细则与医院接待制度仍在落地中——不确定时标注「需人工合规确认」，不得假装已裁定。

## 医药代表与学术推广（中国特有核心）

《医药代表管理办法》将监管从「备案」升级为「全链条管理」。审核 Engagement 时强制检查：

| 检查项 | 通过条件 |
|--------|----------|
| 人员 | 开展学术推广的人员已备案；新聘符合学历与培训考核要求 |
| 主体 | MAH 对自有及委托 CSO/第三方推广承担管理责任；合同含合规与违约条款 |
| 场所程序 | 在医疗卫生机构开展活动：取得机构同意，按机构台账/登记要求执行 |
| 内容边界 | 传递、沟通、反馈药品信息与学术推广；不承担销售任务、不统方 |
| 费用 | 讲者/顾问服务真实、必要；报酬符合公允市场价值（FMV）；可审计交付物 |
| 留痕 | 邀请、议程、材料版本、签到/参会真实性、费用凭证可追溯 |

删除试行办法中对会议形式的正面枚举，**不等于禁止**真实、合理、必要的企业学术会议；但程序与费用公允性要求上升。输出建议时写清「须机构同意」，勿写成「默认可办」。

## 声明与证据（Claim Substantiation）

每条疗效/安全性/比较声明须有可随 MLR 流转的证据包。

| 层级 | 证据类型 | 可接受用途 |
|------|----------|------------|
| 1 | 充分效能 RCT，同行评议 | 主要疗效与安全性声明 |
| 2 | 系统评价 / Meta（基于 Tier 1） | 汇总性或类别比较（仍须谨慎） |
| 3 | 观察性研究 / RWE | 支持性或情境性；不可单独支撑疗效定论 |
| 4 | 病例系列、专家意见 | 背景语境；不可单独支撑疗效 |

规则：

- Tier 3/4 单独支撑的表述须标明证据等级，不得写成既定事实。
- 选择性引用（只报阳性终点、隐瞒共主要/关键阴性终点）一律不通过。
- **适应症内外**以现行中国批准说明书为准。
- 比较声明需要头对头证据；跨试验间接比较须明示，且不得支撑优势声明。
- 中文最高级与「首选一线」等措辞按说明书与指南身份严格限制；指南推荐 ≠ 可对公众做促销级最高级。

## 公平平衡与受众隔离

- 对 HCP：获益与主要风险信息应同屏/同材料可得；不得把风险藏在难读缩略或未附说明书要点的话术里。
- 对公众：处方药不得做产品功效广告式传播；疾病认知教育不得被设计成指向未对公众可推广产品的隐性促销。
- 企微、公众号、视频号、社群、直播与线下会适用同一套声明标准；「私域」不是低风险区。

## MLR 发布前审核

| 角色 | 审核范围 |
|------|----------|
| 医学 Medical | 临床准确性、证据、适应症范围、风险信息是否充分 |
| 法务 Legal | 广告法/反不正当竞争、商业贿赂与第三方风险、合同与隐私 |
| 注册/法规 Regulatory | 与说明书及监管口径一致、渠道是否允许该信息类型 |

- 三方一致批准方可外发；二比一无效。
- 改动声明、风险表述或数据呈现后须重审相关部分。
- 保留版本、意见和批准记录（建议不少于企业 SOP 与潜在执法调取所需年限，通常 ≥3 年）。

## 超适应症 / 在研产品

- 促销性沟通（含被设计为偏向未批适应症的疾病教育）在获批前禁止。
- **医学信息被动响应**：HCP 主动、非诱导性询问超说明书信息时，可由独立于市场推广的医学信息职能以非促销、平衡、可记录方式答复。
- **科学交流例外**狭窄：限于医学事务主导的真诚学术交流，禁止「市场话术走医学通道」规避审核。
- 在研产品不得在促销材料中使用疗效语言或预设获批的人群定向。

## HCP 互动、讲者与价值转移

中国无美国 Sunshine 式全国统一公开支付库，但**反贿赂与真实性**要求不低，且备案平台可公示违法违规信息。

操作规则：

- 讲者费、顾问费、咨询费须有独立或成文的 FMV 依据；明显高于公允区间视为高风险。
- 一切对 HCP 的价值转移（餐费、交通、礼物、赞助名额）须可追踪、可解释、与真实学术/服务匹配。
- 禁止以学术机会、讲者身份换取处方或进院承诺。
- 捐赠/资助须公益、透明、与销售隔离；不得作为准入或处方交换。
- 第三方（会议公司、CSO、数字化供应商）须准入、合同合规条款、交付物与费用审计；MAH 责任不因外包消失。

## 数字化与企微场景（中国高频）

| 场景 | 合规要点 |
|------|----------|
| 企微/公众号推送 | MLR 审核后的内容版本；医生身份与授权范围；频控防骚扰 |
| 线上会/腾讯会议等 | 参会真实性、材料水印/录制留痕、讲者与议程一致 |
| AI 生成话术/闪卡 | 生成后仍须 MLR；禁止模型编造说明书外声明 |
| 患者教育 / PSP | 不得诱导处方；患者个人信息符合 PIPL；药物警戒路径清晰 |
| 统方与商业数据 | 禁止要求医疗机构工作人员统计个人处方；CRM 不得承接非法处方数据 |

## 个人信息（PIPL，非 HIPAA）

- 健康与医疗相关个人信息属敏感个人信息：处理需具备合法性基础，营销/画像类用途通常需**单独同意**，目的与媒介写清楚。
- 患者证言、肖像、病案故事用于宣传前，须有足以覆盖宣传用途的知情同意与肖像授权；不得用一般诊疗同意替代。
- 活动分析系统避免将病历号、诊断、处方明细直接或可重识别方式送入广告/外部平台；第三方 SDK/像素上健康场景页面前做合规评估。
- HCP 联系方式用于企微运营须来源合法、用途匹配，支持退出。

## 输出格式（强制）

审核或起草涉中国 HCP Engagement 内容时，使用以下结构：

```text
## 合规结论
通过 | 附条件通过 | 拒绝

## Fail-fast 命中项
- （无 / 列出触发的规则）

## 风险清单
| 风险点 | 严重度(高/中/低) | 依据(法规/RDPAC/办法/说明书) | 建议处置 |

## 必须保留的约束提示（写入对外文案旁注）
- 例：须医疗卫生机构同意；代表须已备案；费用须 FMV；仅限说明书范围

## 待人工确认
- （实施细则未明、客户 SOP 缺失、说明书版本未提供等）

## as_of
YYYY-MM-DD
```

生成 Engagement 建议时：每条可执行动作旁标注合规约束；无合规依据支撑的互动形式标为「需人工合规确认」，不得写成默许。

## 反模式

| 反模式 | 危害机制 | 合规替代 |
|--------|----------|----------|
| 诱导式超适应症提问（「有没有考虑用于说明书外人群？」） | 伪装成科学交流的促销 | 围绕批准适应症沟通；超说明书走医学信息被动响应 |
| 「请专家读脚本 + 直播挂链」推处方药 | 科普/广告红线 | 砍掉公众促销路径；HCP 渠道走 MLR 材料 |
| 无医院同意的院内科室会 | 违反管理办法程序要求 | 先完成机构登记/同意再邀请 |
| 讲课费远超 FMV 或无交付物 | 商业贿赂外观 | FMV 定价 + 真实议程/讲稿/答疑记录 |
| 企微群发未审核疗效话术 | 私域放大违规声明 | 统一内容库 + MLR 版本号 |
| 用 CSO 隔离 MAH 责任 | 办法明确持有人主体责任 | 合同嵌合规 + MAH 持续监督 |
| 把销量/处方潜力写入代表 KPI 并与学术活动绑定 | 销售任务与学术推广混同 | 学术目标与商业目标组织隔离 |
