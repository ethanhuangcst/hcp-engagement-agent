# 制药行业 HCP Personalized Engagement Assistant
- 为药企量身定做的，为 HCP (Health Care Professional) 建立数字分身，提供个性化 Engagement 的建议
- 内建 hcp-twin-mcp MCP，全网检索 HCP 的信息，包括个人信息、职业轨迹、科研动向、活动热力等, 为 HCP 生成数字分身，形成包括科研方向、兴趣点等在内的 HCP Insights
- 搭建 medical-knowledge-base RAG 知识库，包含全科医学知识
- 内建 hcp-engagement-agent 智能体，根据 HCP 数字分身产生的 HCP Insights, 推荐个性化 engagement 建议

# 产品包含：
## 一个 web app "HCP Personalized Engagement Assistant" 作为交互入口
- "HCP Virtual Twin": 通过一个UI界面获得 HCP 基本信息，然后调用 hcp-twin-mcp 在后台形成 HCP Virtual Twin
- "HCP Insights": 一个UI界面，在形成 HCP Virtual Twin 后，展现该 HCP 的洞察，包括职业轨迹、科研动向、活动热力、兴趣点等
- "HCP Engagement Options": 一个UI界面，调用 hcp-engagement-agent, 根据之前形成的洞察，提出个性化的 HCP Engagement Options
- “HCP Engagement Assistant”: 一个对话风格的界面，可以直接和 hcp-engagement-agent，在之前的 HCP Engagement Options 基础上继续改进，或者随意提问 

## hcp-twin-mcp MCP
- 通过爬虫，在全网找到该医生相关的所有信息，包括职业轨迹、文献、论文、科研动态、活动热力等
- 建立 HCP Virtual Twin (数字分身)，存在本地json文件
- 形成 HCP Insights 洞察：HCP 在做什么，对什么感兴趣，想要什么等关键信息

## medical-knowledge-base RAG
- 全科医学知识库，找到医生对应专业的最前沿学术资料
- HCP Engagement 的合规文件

## hcp-engagement-agent 智能体
- 根据 HCP Virtual Twin 产生的洞察
- 从 medical-knowledge-base 获得的学术知识
- 结合从 medical-knowledge-base 获得的合规知识
- 推荐个性化 HCP Engagement 方案
