# 部署说明

## 主库（MySQL）

| 项 | 值 |
|----|-----|
| 引擎 | MySQL 8.x（兼容 MariaDB 10.x+，需支持 `INSERT … AS new ON DUPLICATE KEY UPDATE`） |
| 主机 | `38.55.199.241` |
| 端口 | `3306` |
| 用户 | `root` |
| 库名 | `hca`（约定；以实例实际库名为准） |
| 密码 | **仅**写入本机 `.env`，禁止提交 Git |

```bash
# .env（密码须 URL 编码，例如 @ → %40）
DATABASE_URL=mysql://root:YOUR_PASSWORD@38.55.199.241:3306/hca
```

BFF、`hcp-twin-mcp`、Agent、`medical-kb` **共用**同一 `DATABASE_URL`。向量仍在本地/内网 **Qdrant**，不进 MySQL。

### 建表与存量迁移

```bash
# 仅建表（空库或幂等）
npm run db:migrate

# MySQL → MySQL（换主机时；默认源读 .env.mysql-old）
npm run db:migrate:mysql-to-mysql

# 从旧 Postgres 拷贝（首次迁库遗留）
# SOURCE_DATABASE_URL=postgresql://…
npm run db:migrate:pg-to-mysql
```

运行时客户端为 `@hca/db`（`mysql2`）；迁移 SQL 在 `packages/db/migrations/`。

## Docker Compose（本机 / 边缘）

Compose **不本地 build**应用镜像，只拉取 GitHub Actions 推送到 GHCR 的制品；Qdrant 仍用官方镜像。MySQL **不在** compose 内启动。

| 服务 | 镜像 | 端口 |
|------|------|------|
| `web` | `ghcr.io/ethanhuangcst/hcp-engagement-agent/web:${IMAGE_TAG:-latest}` | `3001` |
| `hcp-twin-mcp` | `ghcr.io/ethanhuangcst/hcp-engagement-agent/hcp-twin-mcp:${IMAGE_TAG:-latest}` | `3200` |
| `qdrant` | `qdrant/qdrant:v1.14.1` | `127.0.0.1:6333` |

```bash
cp .env.example .env   # 填 DATABASE_URL（+ LLM 等）

# GHCR 私有包需登录（公开包可跳过）
echo "$GITHUB_TOKEN" | docker login ghcr.io -u YOUR_GITHUB_USER --password-stdin

docker compose pull
docker compose up -d

# 指定版本（CI 标签：latest / main / sha-<short> / semver）
IMAGE_TAG=sha-06d2dc8 docker compose up -d
```

本地改代码调试仍用 `npm run dev:web` / `npm run start:hcp-twin-mcp`。Dockerfile 仅供 CI 构建，见下节。

> Web 镜像（`bookworm-slim`）**不含** `libonnxruntime`。确认保存 Twin 不依赖 Xenova；学术知识库 ingest 若在 web 进程内触发且未配置 `EMBEDDING_BASE_URL`，可能跳过/失败，不影响 Twin 落库。RAG 灌库优先用本机 `npm run` 或单独 worker。

## CI 镜像构建（GHCR）

[`.github/workflows/docker-build.yml`](../.github/workflows/docker-build.yml)：

| 事件 | 行为 |
|------|------|
| PR | 只 build，验证 Dockerfile |
| 推送 `main` / `master` | build + push（含 `latest`） |
| 标签 `v*` | build + push（semver 标签） |
| `workflow_dispatch` | 手动触发 |

制品路径：

- `ghcr.io/ethanhuangcst/hcp-engagement-agent/web`
- `ghcr.io/ethanhuangcst/hcp-engagement-agent/hcp-twin-mcp`

Dockerfile：`docker/Dockerfile.web`、`docker/Dockerfile.mcp`。
