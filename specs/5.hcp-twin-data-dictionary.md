## 1. 范围与原则

### 1.1 Twin 是什么

HCP Virtual Twin（医疗专业人士数字分身）是**可审计的公开信息结构化画像**，用于：

- 展示 HCP Insights（UI）
- 驱动 `get_twin_insights` → Engagement Options（Agent + cn-hcp-pro）
- 触发 medical-kb 专科按需 ingest（`specialties` / `themes`）

**不是**：CRM 客户卡、处方分层库、非公开拜访记录库。

### 1.2 持久化（Postgres）

业务 Twin / Insights 存远程 **MySQL**（见 [`4.install-dependencies.md`](./4.install-dependencies.md) §7）：

| 逻辑文档 | 落点（示意） |
|----------|--------------|
| identity | `hcp_twins.identity` JSONB |
| twin（profile + career + research + activity + …） | `hcp_twins.twin` JSONB |
| insights | `hcp_insights.payload` JSONB |
| 可选大字段拆分 | 同库附加列或子表；**字段名保持一致** |

验收 fixture（JSON 文件）仅用于导入/对照，**不是**运行时主存储。逻辑合并视图见 fixture。

### 1.3 通用字段约定

凡**事实性**记录（非纯推断）应尽可能包含：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `source_url` | string | 事实记录建议有 | 溯源 URL |
| `source_type` | enum | 否 | 见 §12.1 |
| `as_of` | date (ISO) | 是 | 采集或确认日 |
| `confidence` | enum | 是 | `high` \| `medium` \| `low` |
| `evidence_snippet` | string | 否 | 短摘录 |
| `conflict_note` | string | 否 | 多源冲突说明 |

**推断性**字段（Insights、`opportunities` / 旧名 `may_want`、`*_hypothesis`）须可追溯到 `evidence_refs[]`，不得伪装成事实。

### 1.4 合规红线（cn-hcp-compliance）

| 禁止写入 Twin | 依据 |
|---------------|------|
| 处方量、份额、统方、销量潜力评分 | 《医药代表管理办法》负面清单 |
| 非公开 CRM 拜访记录 | 不得冒充公开活动热力 |
| 患者病历、可识别患者信息 | PIPL |
| 未授权私域联系方式（手机/微信）用于营销画像 | PIPL |
| 产品适应症、促销话术、MLR 状态 | 属租户 `data/tenants/`，非 Twin |

### 3.2 external_ids / AuthorIds（文献检索号码）

分身须能稳定拉取专业论文。**文献作者标识符**写在 `profile.external_ids`（身份侧镜像）与 `research.author_ids`（**灌库权威副本**，字段集同 §3.2.1）。二者应保持一致；冲突时以 `research.author_ids` 为准。

`disambiguation_status = resolved` 时：**至少填入活跃 P0 文献号之一**（orcid / pubmed_author / openalex；`null` 表示已查无），禁止仅靠中文姓名灌 PubMed。

#### 3.2.1 AuthorIds — 论文检索用号码

| 字段 | 中文名 | 类型 | 必填 | P | 检索用途 / 格式约定 |
|------|--------|------|------|---|----------------------|
| `orcid` | ORCID | string \| null | 条件* | P0 | 优先绑定；`0000-0000-0000-000X`（含连字符） |
| `pubmed_author` | PubMed / NCBI Author ID | string \| null | 条件* | P0 | Computed Authors / Author Clusters；E-utilities 按作者簇拉文 |
| `openalex` | OpenAlex Author ID（主） | string \| null | 条件* | P0 | `A` + 数字或完整 URL 末段；**主**作者簇；免费作者作品 API |
| `openalex_aliases` | OpenAlex Author ID（别名） | string[] | 否 | P0 | 同人其余已确认 OpenAlex 簇；去重且**不含** `openalex`；Stage C 与主 ID **联合**拉 works 后按 DOI/标题去重（见 ADR-004） |
| `google_scholar` | Google Scholar User ID | string \| null | 否 | — | **非活跃采集源**（无官方 API / 国内不稳）；字段可保留不灌库 |
| `scopus_author_id` | Scopus Author ID | string \| null | 否 | — | **非活跃**（需订阅） |
| `wos_researcher_id` | WoS ResearcherID | string \| null | 否 | — | **非活跃**（需订阅） |
| `semantic_scholar` | Semantic Scholar Author ID | string \| null | 否 | — | **非活跃**（国内访问不稳） |
| `dimensions` | Dimensions Researcher ID | string \| null | 否 | — | **非活跃** |
| `cnki_scholar` | 知网学者 / 作者标识 | string \| null | 否 | — | **非活跃**（常需机构账号） |
| `wanfang_author` | 万方作者标识 | string \| null | 否 | — | **非活跃** |

\*条件必填：`resolved` 时 **orcid / pubmed_author / openalex** 中 **≥1 个非空**（活跃 P0；见 [`literature-sources.md`](../knowledge/mcp-hcp-virtual-twin/literature-sources.md)）。仅有 `openalex_aliases` 而无主 `openalex` 时，实现须将 aliases[0] 提升为主 ID 后再视为满足 P0。

同人多 OpenAlex 簇：消歧确认可合并多个候选的 OpenAlex ID → 一个 Twin（`openalex` + `openalex_aliases`）；见 [ADR-004](../docs/adr/ADR-004-multi-openalex-ids.md)。

#### 3.2.2 ExternalIds — 在 AuthorIds 之上的身份侧字段

| 字段 | 中文名 | 类型 | 必填 | P | 说明 |
|------|--------|------|------|---|------|
| （嵌入） | AuthorIds 全部字段 | — | — | — | 与 §3.2.1 同构 |
| `hospital_expert_page_id` | 医院专家页 ID | string \| null | 否 | P1 | 站内标识，非论文检索 |
| `notes` | 消歧备注 | string \| null | 否 | P1 | 同名冲突、曾用机构等 |

#### 3.2.3 检索优先级（hcp-twin-mcp · 活跃源）

```text
1. orcid            → ORCID works / PubMed ORCID 过滤
2. pubmed_author    → E-utilities 作者簇
3. openalex         → OpenAlex works-by-author
4. europe_pmc       → 补 PMID / 交叉验证
5. crossref         → DOI 题录归并
6. trials (P2)      → ClinicalTrials.gov 旁证
fallback            → name_en + affiliation 人工复核（构建日志；不替代 AuthorIds）
```

活跃源须满足：公开 API、国内可访问、免登录、无爬虫。

### 16.3 验收断言（建议自动化）

| ID | 断言 |
|----|------|
| A1 | §16.1 每行可调用 `resolve_hcp_identity`，返回 `candidates[]` 非空（人候选含姓名/机构；或 unresolved 空列表） |
| A2 | 8 个 `specialty_group` 均出现；任一组人数 ∈ {2,3}；总人数 = 20 |
| A3 | 每 `specialty_group` 至少含 1×T1 与 1×T2 |
| A4 | MCP 产出 `specialties` 与样本 `specialty_group` 同域（肺癌样本不得只命中肾移植等） |
| A5 | 跨专科 Options **不串用**他科核心话术（如心血管样本不出现肾移植随访主题） |
| A6 | `insights.engagement_hints.compliance_cautions` 非空 |
| A7 | T1 样本默认更偏 MSL/学术渠道假设；T2 可测代表+区域会组合（推断，作 harness 检查项） |
| A8 | 禁止字段（处方量、统方等）不得出现在 Twin 输出 |
| A9 | `disambiguation_status=resolved` 时 `research.author_ids` 至少含一个非空活跃 P0 号（orcid / pubmed_author / openalex） |
